# 覆巢之下 · 股市模拟游戏（v0.1.0 深度版）

> 你是一名投资经理。初始资金 **10,000 虚拟货币**，共 **60 个交易日**，在 T+1、双向手续费、
> ±10% 涨跌停、做空保证金与强平、宏观周期（利率×通胀）规则下让总资产最大化，
> 并与覆巢指数、机构平均对比超额收益。

---

## 〇、v0.1.0 新增（深度版）

### 1. 宏观经济层
- **通胀（低1%/中3%/高8%）× 利率周期（宽松1%/中性3%/紧缩6%）** 状态机，每 **5-8 个交易日**一次宏观事件驱动迁移：
  GDP 超预期 / 油价冲击 / 央行降息 / 央行加息 / 通胀抬头 / 通胀降温 / 就业报告 / **黑天鹅危机**（约 20% 概率，每局最多 1 次）。
- **核心公式**：`股票基础价值 = 预期股息 ÷ 无风险利率`（利率↑ → 估值中枢↓ 杀估值；通胀↑ → 利润率↓，周期股更敏感）。
  均值回归与机构估值均锚定该宏观基础价值。
- **央行反应规则**：高通胀持续 2 期 → 被迫加息；覆巢指数 5 日跌超 6% → 降息。
- **黑天鹅危机**：流动性冻结 3 天，股市 -10~-20%、股债双杀、**黄金 +10~+20%**；宏观事件以"宏观"新闻显示在新闻流。

### 2. 做空机制
- 借券卖空，冻结 **50% 保证金**；可借余量 = 流通量 × 20%，借完拒开。
- **强平线**：浮亏达保证金 80% 自动市价平仓（进成交流水）；**做空 T+1**（次日才能平仓）。
- **借券费 0.02%/日**（现金扣，逐笔记流水）；杠杆上限：总保证金 ≤ 2×初始资金（防止极端行情现金为负）。

### 3. 资产扩展（指数3 + 债券2 + 商品2）
| 类别 | 标的 | 定价逻辑 |
|---|---|---|
| 指数（不可交易） | 覆巢指数（市值加权）/ 科技指数 / 能源指数 / 金融指数 | 成分股市值加权，温度计 + 业绩基准 |
| 债券 | 十年期国债 / 汇通企业债 | 价格随利率**反向**；企业债含信用利差（通胀+金融新闻） |
| 商品 | 黄金（避险）/ 原油（能源联动） | 危机 +10~20%、高通胀 +5~10%；油价冲击事件 |

- 债券/商品可交易：T+1、手续费同股票、无涨跌停但单日波动 ≤ **±6%**。

### 4. 交易者分层
- **散户**（数百聚合）：羊群追涨杀跌、对新闻过度反应；**机构**（6 家）：趋势 + 基本面（估值中枢），单笔撬动 ±1~3%，紧缩期回避科技；**游资**（聚合）：隔日拉高 → 出货制造异动。
- 每日成交量拆分为 **散户/机构/游资** 占比（K线图副图堆叠显示）；单日异动超阈值 → **龙虎榜风格信号**（机构净买入 / 游资出逃 / 散户主导）。

### 5. 图表与面板
- **K线图**：选中标的显示日 K（蜡烛图）+ 成交量副图（散户/机构/游资堆叠），ECharts 按需引入。
- **净值曲线**：玩家 vs 机构平均 vs 覆巢指数（起点 100 归一）。
- **持仓饼图**：按行业 / 按个股两种视角。
- **成交流水**：买卖/做空/平仓/强平/借券费/手续费逐笔记录，可按标的筛选。
- **调参面板**（顶栏「调参」）：手续费率、涨跌停幅度、做空保证金率、强平线、借券费率、宏观事件频率、危机概率、散户/机构/游资成交占比；「恢复默认」；改动**下一交易日生效**并写入存档。
- **结算复盘**：总资产/收益率/跑赢覆巢指数/机构平均对比、收益归因 Top/Bottom、交易统计（次数/手续费/胜率）。

### 6. 其他
- 60 交易日；存档 key 升级（旧 v0.0.0 存档自动忽略，优雅重置）；「新游戏」保留。

## 一、基础玩法（沿袭 v0.0.0）

### 1. 市场（8 只虚拟股票）

| 清源水务 | WAT | 公用事业 | 55 | 7 亿 | |

### 2. 每日价格引擎
1. 随机游走 ±1.5%；2. 趋势因子（3 日动量）；3. 均值回归（相对**宏观基础价值**偏离 >15% 拉回）；
4. 新闻影响（个股 ×1.3 / 行业 ×1.0 / 全市场 ×0.7）；5. 交易者分层扰动（散户/机构/游资）；
6. 危机系统性下跌；7. 涨跌停 clamp ±10%；成交量 = 散户/机构/游资构成之和。

### 3. 新闻系统
- 每天 1-3 条 AI 新闻（后端 `POST /api/news`，DeepSeek）+ 前端/后端模板兜底（纯离线可玩）；
- 宏观事件新闻（kind=macro）独立生成并显示。

### 4. 交易规则
- **T+1**（买入/做空次日才能卖出/平仓）；**双向手续费 0.1%，最低 1**；
- 市价/限价单（限价单仅买入/卖出，下一交易日撮合）；做空/平空仅市价；
- 股票 ±10% 涨跌停（涨停不能买、跌停不能卖）；债券/商品 ±6% 日波动。

## 四、已知简化 / 妥协（v0.1.0）

1. **AI 新闻依赖真实网络**：DeepSeek 调用 20 秒后端超时、前端 6 秒超时；超时/失败走模板兜底。
2. **限价单撮合简化**：下一交易日收盘价撮合（买入现价 ≤ 限价、卖出现价 ≥ 限价），无委托队列/滑点；涨跌停日不成交并撤单；做空/平空不支持限价单。
3. **交易者资金池**：散户/游资为聚合资金池（未逐人建模），机构 6 家逐家记账；机构/散户/游资仅交易股票（不持有债券/商品）。
4. **做空简化**：强平按收盘价市价执行；现金不足时部分强平（现金永不为负）；杠杆上限 2×初始资金。
5. **持仓饼图仅统计多头**；空头在持仓表单独展示。
6. **排行榜本轮不做**（本地/云端均未实现，v0.2 预留）。
7. **前端 bundle**：ECharts 按需引入后主 chunk 约 854 kB（gzip 284 kB），vite >500 kB 提示属预期。
8. **宏观平衡性为初稿**：利率 1% → 基础价值 ×3、6% → ×0.5，60 天内可能出现指数大幅波动（宏观择时价值明显），后续实测定调。

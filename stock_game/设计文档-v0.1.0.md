# 《覆巢之下》v0.1.0 设计文档（深度版）

> 目标：把 v0.0.0 从"能玩"升级到"想一直玩"。
> 本版锁定决策（端明ちゃん 拍板）：**60 交易日 · 做空允许强制平仓 · 指数3+债券2+商品2 · 排行榜本轮不做（云端预留）· K线图与调参面板本轮实现**。

---

## 0. 版本目标一句话

让市场"活起来"：宏观周期驱动估值、多资产可配置、对手分层（散户/机构/游资）、玩家能看清自己的钱怎么变多变少。

## 1. 宏观经济层（利率 / 通胀 / 危机）

### 1.1 宏观状态机
- 三个维度：**通胀**（低 1%/中 3%/高 8%）× **利率周期**（宽松 1%/中性 3%/紧缩 6%）
- 每 **5-8 个交易日**随机发生一次宏观事件，推动状态迁移：
  - 事件表：GDP 超预期、油价冲击、央行降息/加息、通胀抬头、就业报告、**黑天鹅危机**（低概率高破坏）
- **央行反应规则**：高通胀 +2 期 → 被迫加息；衰退信号 → 降息

### 1.2 传导链（核心公式）
```
股票基础价值 = 预期股息 / 无风险利率
利率 ↑ → 基础价值 ↓ → 全市场估值中枢下移（杀估值）
通胀 ↑ → 企业成本 ↑ → 利润率 ↓（周期股更敏感）
危机事件 → 流动性冻结：股市 -10~-20%、债券价格波动、黄金 +10~+20%
```

### 1.3 与游戏时长
60 个交易日 ≈ 可容纳 2-3 个完整的"宽松→紧缩"小周期 + 1 次危机窗口，玩家能真实感受到"宏观择时"的价值。

## 2. 做空机制

- **开仓**：借券卖空，占用 **50% 保证金**（卖空金额的 50% 冻结为保证金）
- **可借余量**：每只股票可借上限 = 流通量 × 做空比例上限（默认 20%），借完无法继续做空
- **强平线**：浮亏达到**保证金 80%** → 自动市价强平（平仓买回）；强平记录进成交流水
- **T+1**：做空的仓位次日才能平仓
- **费用**：借券费率每日 0.02%（从现金扣），双向手续费照旧
- 交互：交易面板加"做空/平空"按钮，持仓表区分多/空头寸

## 3. 资产种类（指数3 + 债券2 + 商品2）

| 类别 | 标的 | 定价逻辑 |
|---|---|---|
| 综合指数 | **覆巢指数**（市值加权 8 股） | 成分股实时加权 |
| 行业指数 | 科技指数 / 能源指数 / 金融指数 | 对应行业成分股加权 |
| 国债 | **十年期国债** | 无风险：价格随利率**反向**（利率↑债价↓）；到期收益稳定 |
| 企业债 | **汇通企业债** | 信用利差：发行人公司新闻/行业景气影响价格 |
| 黄金 | **黄金** | 避险：危机事件 +10~20%；高通胀 +5~10%；风险偏好回升回落 |
| 原油 | **原油** | 能源联动：能源行业新闻、油价冲击事件 |

- 指数**不可直接交易**（作为市场温度计 + 业绩基准）；债券/商品可交易（T+1，手续费同股票，无涨跌停但单日波动 ≤ ±6%）
- 玩家在结算时与**覆巢指数**对比超额收益

## 4. 交易者分层（散户 / 机构 / 游资）

### 4.1 三类资金池（每局随机分配规模）
| 类型 | 数量 | 单笔规模 | 行为策略 |
|---|---|---|---|
| **散户** | 数百 | 极小 | 羊群效应：跟随近 3 日涨跌追涨杀跌，放大波动；对新闻反应过度 |
| **机构** | 5-10 家 | 大 | 趋势 + 基本面：参考基础价值与宏观（利率↑减持成长股），单笔能撬动价格 |
| **游资** | 2-3 路 | 中 | 短线脉冲：隔日拉高 → 出货（制造异动），随后回落 |

### 4.2 市场反馈
- **成交量构成**：每日成交量拆分为 散户/机构/游资 占比（图例显示）
- **龙虎榜**：单日异动超阈值的股票，提示"机构净买入/游资出逃"等风格信号
- 价格冲击：单笔机构单可按成交量占比产生 ±1~3% 的盘中扰动

## 5. 资产管理与图表升级

- **净值曲线**：玩家 vs 机构平均 vs 覆巢指数的每日总资产对比（ECharts 多线）
- **持仓饼图**：按行业 + 按个股两种视角（ECharts pie）
- **蜡烛图（K线）**：选中股票显示日 K + 成交量副图（**本轮实现**，替换折线图）
- **成交流水**：所有买卖/分红/强平/费用逐笔记录，可按股筛选
- 顶栏：当日盈亏（红绿）、累计收益率、现金占比醒目化

## 6. 结算与调参面板

- **复盘报告**：
  - 总资产 / 收益率 / 跑赢覆巢指数幅度
  - 收益归因：按个股统计 盈亏贡献 Top/Bottom
  - 交易统计：次数、手续费合计、胜率
- **调参面板**（本轮新增）：顶栏「调参」按钮打开弹窗，可调整：手续费、涨跌停幅度、做空保证金率、强平线、借券费率、宏观事件频率、散户/机构/游资成交占比等；默认值=第 7 节；提供「恢复默认」；改动从下一交易日生效并写入存档
- **本地排行榜本轮不做**（云端排行榜预留，复用撷菁轩 FastAPI+Supabase 模式，v0.2 再接）

## 7. 数值初稿（平衡性起点，后续实测定调）

| 参数 | 默认 |
|---|---|
| 初始资金 | 10,000 |
| 交易日 | 60 |
| 手续费 | 双向 0.1%，最低 1 |
| 涨跌停 | 股票 ±10%；债券/商品 ±6% |
| 做空保证金率 | 50% |
| 强平线 | 保证金 80% 浮亏 |

## 9. 测试点（无头模拟扩展）

- 宏观：利率升降 → 基础价值重估方向正确；危机触发后股市暴跌+黄金大涨
- 做空：保证金不足拒开、浮亏达线强平、可借余量为 0 拒开
- 交易者：成交构成占比在基准 ±10% 内；机构单笔对价格有扰动
- 60 天全流程：现金非负、持仓一致、排行榜写入

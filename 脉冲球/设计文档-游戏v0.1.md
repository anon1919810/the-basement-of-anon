# 《脉冲球》游戏设计文档 v0.1

> 形态：FC×FM 之间——**管理 + 看比赛**（不手操，看小人自动踢球）
> 技术：确定性模拟引擎（复用卡尔特经验）+ Canvas 比赛可视化 + ECharts 图表
> 规则依据：`规则-脉冲球v0.2.md`

---

## 一、核心定位

玩家扮演**教练/经理**：排兵布阵、定战术、管转会与财政；比赛由引擎**自动模拟**，玩家以"看比赛"方式观战（实时/加速/跳节/只看关键时刻）。**无手操**——手操的"手感调校"正是最烧 token 的部分，我们彻底绕开。

## 二、球员属性（四类，0-99，均对应脉冲球规则）

| 类别 | 属性 | 作用（对应规则） |
|---|---|---|
| **技术** | 传球 | 空中传球成功率 → 脉冲积累速度 |
| | 停控 | 球未触地前的停球质量 → 防断脉冲 |
| | 带球 | 7 秒持球限制下的护球 |
| | 射门 | 射门命中率 |
| | 远射 | 18 米外远射加成区命中 |
| **身体** | 速度 | 无球跑位/回追/逼抢 |
| | 体能 | 3×20 净时的续航（逼抢战术上限） |
| | 力量 | 肩对肩/卡位（合理对抗） |
| **精神** | 空间感 | 无球跑位/接应路线——"空间意识"核心 |
| | 预判 | 抢断/拦截传球路线（破坏对方脉冲循环） |
| | 冷静 | **满脉冲(4-5层)时射门加成**——戏剧性来源 |
| | 纪律 | 犯规倾向 → 累计犯规/黄牌风险 |
| | 战术纪律 | 越位陷阱协调（9人制防线） |
| **门将** | 扑救/手抛/出击 | 快反发动（手抛不计脉冲但快）vs 脚传（计脉冲） |

**交互咬合示例**：传球×停控=脉冲速度；速度×体能=逼抢强度；空间感=同组合限制下找第三路线；纪律低=白送 2 分点球；冷静=脉冲 5 的紧张时刻。

## 三、阵型与位置（9 人制）

- 典型阵型：**2-3-2-1**（门将/后卫2/中场3/前腰2/前锋1）或 **2-3-3-1** 等
- 每位置属性权重不同（边路吃速度、中场吃传球空间感、前锋吃射门冷静、后卫吃预判力量）
- 8 场上 + 门将，替补 5（节间 1 次换人、最多 3 人）

## 四、比赛引擎（核心，先模拟后回放）

1. **确定性事件模拟**：比赛按"秒 tick"推进，场上状态 = {控球方, 区域(x,y), 脉冲计数, 比分, 时间}；每 tick 依概率选择事件（传球/停控/带球/抢断/射门/犯规/越位/出界），概率 = 属性×战术×随机(seed)
2. **事件流**：每事件带 时间+位置+参与者 → 生成回放序列
3. **规则落地**：空中传球→脉冲+1（含同组合限制/触地判定）；7 秒出球；越位判定；节末累计平→金球加时；点球大战
4. **可视化回放**：Canvas 小人物按事件流运动（球/脉冲 LED 颜色实时显示！）——**LED 灯带=天然的观赛可视化**，这是我们独有卖点
5. **观赛控制**：实时 / 2x / 4x / 跳过节段 / 只看关键时刻（进球/射门/脉冲5/点球）

## 五、管理模式（FM 风，简化）

- **联赛**：8-10 队单/双循环，赛季 + 积分榜
- **阵容战术**：阵型选择、球员上场、节间换人；战术旋钮：逼抢强度 / 传球风格（空中vs地面）/ 防线高低（越位陷阱）
- **转会**：简单市场（挂牌/报价/合同）；**青训**：潜力+成长；**财政**：预算/工资/奖金
- **士气/体能**：三节制疲劳真实；连胜士气加成

## 六、UI

- 主界面：赛程/阵容/转会/财政/设置
- 比赛界面：Canvas 球场 + 小人 + 脉冲 LED 球 + 实时比分/脉冲/事件日志 + 观赛控制条 + 数据面板（传球成功率/控球率/射门分布）

## 七、版本路线

| 版本 | 内容 |
|---|---|
| **v0.0.0** | 比赛引擎（确定性 9v9 模拟）+ Canvas 可视化回放 + 单场比赛查看 + 基础阵容 |
| v0.1 | 管理模式（联赛/转会/青训/财政/士气体能）+ 战术旋钮 |
| v0.2 | 观赛体验（加速/关键时刻/慢放/数据面板）+ 平衡实测定调 |

## 八、数值初稿（待实测）

- 传球成功率基准 ~75%（空中），随 停控/空间感/逼抢 修正
- 射门命中：基础分脉冲×命中率（脉冲5+冷静加成，命中 ~45%）
- 7 秒出球：持球 tick 数超限概率触发违例
- 体能：每节消耗，低于阈值逼抢强度骤降

## 立体税制

- [x] **六税种**：土地税/人头税/消费税/关税/其他特别税 + 单一商品税，**连续滑块 0%-30%**
  （tax.ts：TAX_MAX=0.3、步进 0.5%）；**阶级负担矩阵**（CLASS_TAX_MATRIX）：
  土地→持地者（地主/大贵族/富农/自耕农）、人头→全体自由民（奴隶免）、消费→市民/工匠/工人/职员、
  关税→商人/资本家、特别→按贸易与运输量；默认税率按国家经济特征（taxDefaults）
- [x] **单一商品税**：**全部 17 商品可选**（粮食/木材/棉花/毛皮/煤炭/铁矿/盐/渔获/木料/布料/铁锭/钢材/工具/武器/帆船/衣物/奢侈品），
  每商品独立滑块 0%-30%，可多选叠加；买方有效价 = 市价×(1+税率)；收入 = 税率 × 成交量（消费+进口+建筑消耗）进国库；
  出口为外国买方不征（见 market.ts）
- [x] **盐回归普通商品**：取消盐税专档（SALT_BASE/TAX_RATES.salt 移除），盐走供需定价（可被选作单一商品税对象）
- [x] **产业链价格传导**：输入品征税 → 下游建筑按税后有效价计成本（economy step 7）→ 成品价格随成本上升
  （market.ts costPush，按 GOODS_LIST 序沿建筑输入链前向传导：煤炭税→铁锭价↑→钢材价↑→工具/武器/船坞价↑）；
  传导过手率 COST_PUSH_PASS=0.85，价格仍 clamp 在 0.4~2.5×基础价
- [x] 税制显示：NationPanel「税收」页——五税种滑块 + 全部商品税滑块列表（资源/半成品/成品筛选）+ 各税种实收 +
  阶级负担明细（谁在交多少）+ 传导提示（"煤炭税 15% → 钢材成本 +X%"）

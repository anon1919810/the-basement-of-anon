## 本地/区域/国家市场（市场层级）

- [x] **本地市场（县）**：县内自产自销，无运费，价格 = 基础 × 县内供需比（clamp 0.4~2.5）
- [x] **区域市场（省）**：县间贸易，省内运费（距离×地形，复用 logistics：countyFreightFactor）
- [x] **国家市场**：省间调运，跨省运费更高（provinceFreightFactor 平均）
- [x] 层级价格：各级供需定价，盈余向上流动、缺口向下补足（省池调剂 + 国家库存补足）；价格信号跨层传导（国家→区域 15% 权重 → 本地 20% 权重）
- [x] 守恒：生产（县产+工厂）+ 进口 = 消费（县+政府）+ 出口 + Δ库存（sim 逐月断言，容差 1%）

- [x] **POP 投资收入**：精英/富裕 POP（工匠/工程师）从全国资本回报池（贸易顺差 40% + 工业利润 25%）按财富占比分配，并入 POP 收入（工资 + 投资）
- [x] **玩家投资面板**：投资项目列表（纺织厂/冶铁厂/船坞，按省份可选，受省份资源/基建解锁），建造成本（国库投入）+ 工期（数月）→ 投产后每月按该商品国家市场价 × 产能产生回报（进国库），市价低迷时亏损（回报 = 产能 × (市价 − 运营成本)）

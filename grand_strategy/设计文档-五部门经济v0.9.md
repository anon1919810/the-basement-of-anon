## 四、运力机制（核心新系统）

1. **运力 = 商品**：公路/铁路/港口 有配方、产 `transport` 进市场；可被其他建筑 `/运力` 加强项采购，也可出口
2. **地形乘数**：省内基建建筑产出 × 地形适宜系数（平原公路 ×1.4 / 山区铁路 ×1.6 / 港口沿海 ×1.5），产出有上限（地形容量）
3. **贸易影响**：省 `transport` 存量决定跨省调运容量与运费系数（替换/增强现 `routeCoef`）；全国运力不足 → 省际价差扩大、短缺加剧
4. **无建筑不产运力**（运力必须由基建投资产生——这是"工业化的代价"）

## 五、双轨制：国营 vs 私营

| | 国营 | 私营 |
|---|---|---|
| 投资 | 国库（现状机制） | 资本家/银行家财富池自动投资、自动扩建 |
| 利润 | 入国库 | 流入资本阶级财富（→ 财富系数 → 奢侈品需求/政治影响力）|
| 玩家控制 | 直接投资 | 政策调节（执照、税率、国有化法案）|
| 产能 | 受国库预算约束 | 受资本财富积累约束（富者愈富）|

> 双轨并存：同一省可既有国营又有私营同类建筑。私营建筑产出同样进市场、同样纳税。

## 六、成瘾物（咖啡/烟草）

- **需求刚性**：需求价格弹性低（上瘾者照买），价格高也不明显抑制需求
- **缺货暴怒**：供应不足时幸福度惩罚 ×2（其他商品 ×1）
- **天然税源**：适合高税率（烟酒税传统），且税率对需求抑制弱 → 高税率 = 高收入低民怨损失

## 七、职业与资质（8 职业，重构）

现有 4 职业（farmer/miner/artisan/engineer）扩展：
**奴隶 slave / 自耕农 peasant / 工人 worker / 职员 clerk / 工程师 engineer / 市民 burgher / 资本家 capitalist / 银行家 banker**

- 技能链（体力侧）：slave → peasant → worker → clerk → engineer
- 资本侧（非体力从业）：burgher / capitalist / banker 参与加工/工业/基建的**管理出资**角色
- 建筑资质 = 允许职业集合（上表）；产能 = 合格职业 POP 规模 × 效率
- 转职/识字率门槛沿用 `JOB_LADDER`/`LITERACY_REQ` 机制扩展

## 八、自然经济底子（无建筑产出）

- **农业/矿业省份无建筑也按从业者数量少量产出**（沿用 `FARMER_EXTRA_OUTPUT`/`MINER_OUTPUT` 扩展新资源：小麦/肉/石料/硫/铜…）
- 无建筑产出**不受 /加强项 加成**（体现"原始生产"与"工业化生产"的差距）
- 意义：即使完全不建厂，人口也能维持基本生存（粮食/渔/木），但无工具无机器 → 效率天花板低

## 十、设计纪要 2026-08（第二轮讨论定稿）

### 10.1 运力：动态稀缺 + 可选购
- **乘数加成**：建筑启用 `/运力` 加强项 = 按乘数提效，同时降低生产与销售物流成本（省价上浮系数 ↓）
- **可选购**：运力盈余省份的建筑**自行决定是否启用**（玩家逐建筑开关）；启用即按市场价购买运力
- **消耗量设计**（每产能单位/月，待实测）：采矿 0.5 ＞ 工业 0.4 ＞ 加工 0.3 ＞ 农业 0.1 ＞ 基建 0
- **动态稀缺**：运力有**限额**（省地形容量 × 基建/科技）；贸易消耗运力 → 运力紧张 → 运力市价上涨 → 省内建筑购买成本上升 → 被迫关闭加成或提高售价
- 运力=商品进市场（供需定价 clamp 同其他商品），可跨省调运、可出口

### 10.2 建筑上限与双轨（私营动态）
- **上限**：每省每建筑 `maxCount = f(地形容量, 基建等级, 科技)`；基建改善/科技进步 → 上限上涨
- **地形规则**：省资源类型决定"能建什么"，地形（海拔/温度/降水，已有数据）决定"建多少"（如山区煤矿上限 3、平原农场上限 8）
- **私营**：按经营状况**自动扩建**（月利润率 > 阈值 → 升级），**不得超过上限**；亏损 → 降级 → **破产倒闭**（建筑消失，失业 POP）
- **国营**：亏损**不倒闭**，国家自动调节等级（逐级降，最低保 1 级）——"国营稳、私营激进"
- **玩家干预**：税率工具 + 财政政策（补贴/减税/**有偿国有化**/特许执照）；货币政策（铸币/通胀/利率）**后置**，基础稳定后再加
- **有偿国有化**：没收私营按市值补偿（财政支出）；不补偿 → 资本家暴怒、动乱风险

### 10.3 职业、阶级、资质三分（架构级）
- **职业 Job**（干什么活，9 种）：生产侧 奴隶→自耕农→工人→技术工人→工程师；管理 职员；资本侧 商人→资本家→银行家
- **阶级 Class**（纯财富地位，7 级，改名）：贵族 / 富裕 / 中产 / 温饱 / 贫困 / 赤贫 / 奴役——不再含职业词，完全解耦
- **流动**：财富积累 → 阶级上升（自耕农→市民→资本家）；失业/破产 → 下降；教育 → 职业资质（技校→技术工人、大学→工程师、识字→职员）
- **资质**（从业资格）：建筑资质 = 允许职业集合（前表）；产能 = 合格职业 POP × 效率
- 移除 `INITIAL_CLASS_MIX`（职业→阶级概率绑定），阶级由经济内生演化

### 10.4 消费乘数矩阵
- **所有日用品/消耗品**设 商品×阶级（7 级财富）权重 + 商品×职业（9 种）乘数：
  - 上层比下层消耗更多 糖/奢侈品/高级食物；工人比农民更多烟草；农民多粗粮
  - 消费性商品（约 12 种）设矩阵；生产性商品（铁锭/钢材等）不设
- 需求 = 人口规模 × 阶级权重 × 职业乘数 × 幸福度/财富系数

## 十一、投资池设计定稿（2026-08 第三轮讨论，端明ちゃん 定稿）

> **状态：设计已定稿，代码待实现**（因半成品市场记账深层 bug 需先修，见下）

### 11.1 核心模型：统一财富池为投资池
- **投资池流入 = Σ(各人群分红/盈余 × 投资贡献比例 × 投资效率修正)**，汇入投资池用于私营自动建设
- **贡献比例**（分红/盈余中"应缴"投资比例）：
  - 银行家 20% / 资本家 15% / 贵族 10% / 地主 7% / 商人·店主·自耕农 5%
- **投资效率修正**（经济体制法律，试验数值）：
  - **传统主义**：资本/贵族/地主/农民再投资效率 ×0.5
  - **自由放任**：银行家/资本家/店主 ×1.25，商人 ×1.15
  - **龙本主义**（卡尔特专属）：自耕农/地主/贵族 ×1.5
- **计算公式**：`最终投资额 = 该人群分红 × 贡献比例 × 效率修正`，Σ 即为投资池流入
  - 例（自由放任）：炼钢厂付资本家 1000 分红 → 1000×20%×1.25 = 250 入池
  - 例（传统主义）：1000×20%×0.5 = 100 入池
- **记账口径**：贡献按记账不实际扣减 POP 分红（避免生活水平连锁触发改行导致市场账本抖动）
- **私营利润路径**：私营利润 100% 先入分红池（capitalPool）→ 资本侧分红（investIncome）→ 按比例贡献投资池；国营利润归国库
- **净分红**：资本侧到手 = 分红 × (1 − 比例×效率)（设计语义，实现时若触发守恒问题改记账口径）

### 11.2 实现前置：半成品市场记账深层 bug（必须先修）
- **症状**：私营+国营混合建筑后，面粉/皮毛/布料/糖/肉类/运力的按省守恒出现 0.3~2.7 的差值（第 480~1650 日边缘省）
- **疑似根因**：下游建筑 `anyOf` 预扣（economy 段）与市场省际调运（market 段）对半成品的记账顺序/口径不一致；运力贸易消耗（provFreight eat）与 transport 自身市场流程的库存交互
- **修法方向**：统一"建筑预扣 → 市场结算"的口径（预扣即消费、调运即补货），或半成品不做省际调运（本地消费/库存）；修后 sim 断言应全过（117380 基线）

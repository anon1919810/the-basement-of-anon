## 经济全循环（核心）

- [x] **聚合 POP**：职业（农民/矿工/工匠/工程师）× 种族（八族，按国家主体种族初始化），每省分组；需求四件套（粮食/衣物/住房/燃料）满足度 → 幸福度 → 生产效率倍率（0.5-1.2）
- [x] **劳动力市场**：工资=基础工资×岗位供需比（clamp 0.5~2.0）；识字率解锁技能梯子（0.10/0.25/0.50）；**转职**操作（代价=3 个月产出减半）
- [x] **人口增长**：粮食盈余×和平系数×政策系数；住房容量设上限（省人口 ≤ 容量，基建提升）；人口质量（识字率/健康）随教育/卫生支出提升
- [x] **市场与价格**：国家市场供需定价（基础价×供需比，clamp 0.4~2.5 倍）；价格信号（供需比+趋势）引导生产；**简化国际贸易**（盈余出口/缺口进口，世界价+关税）；贸易额受商路（海路=港口/陆路=道路）影响
- [x] **物流运输**：跨省运费=距离×地形系数（山地贵、沿海便宜）；基建（道路/港口）降运费；同省内免运费
- [x] **财政**：土地/人头/关税/盐税 × 税率档 → 国库；支出（行政/军/基建/宫廷/卫生）；基建投入提升产能（工业/农业）并降运费
- [x] **反馈环**：良性（基建→产能→税收）与恶性（苛税→幸福度↓→效率↓→人口外流→衰退）都真实

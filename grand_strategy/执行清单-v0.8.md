> 状态：`[x]` = 已完成（含提交 hash）

## 市场中心模型

- [x] **省为结算单元**：移除"国家统一市场"实体；每省独立供需/价格（省价差异化）
- [x] **流向链条**：建筑产出 → ①商品税(产地) → ②本地市场(县) → ③多余按省价流入省市场(集散，运费+运力/基建税作商品税) → ④省间流通 → ⑤出口权门槛 → ⑥入国际市场征关税
- [x] **出口权**：沿海/港口省默认获权；内陆省可授予/收回（点选管理）；未获权省商品须流入获权省才能出口
- [x] **开放度**：国家"开放度"决定接入世界市场（默认不开放=不贸易；开放=按世界价进出口+关税）；外交系统不做
- [x] **价格差异化**：省际价差驱动流动（受运费/税制约）；同商品不同省可有不同价格
- [x] 税制衔接：运力税/基建税 = 商品税类（运输/吨位计税）

## 验证与交付

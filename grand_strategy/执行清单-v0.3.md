## 阶级系统（POP 增加"阶级"维度）

- [x] **阶级定义** `classes.ts`：7 级（大贵族/资本家/技术阶层/市民工匠/自耕农工人/无业佃农/奴隶），含成员/税收系数(0.2→1.6, 奴隶0)/奢侈品(仅1-3级)/政治权重/消费倍率/基础幸福/资本回报权重/动乱权重/地税权重
- [x] **POP 重构**：POP = {阶级×职业×种族}；各国初始阶级分布（帝国=农奴制：奴隶37%+佃农+大贵族/地主，少量官僚技术阶层；洛林=市民/工人/资本家/官僚为主，无奴隶；伊尼亚斯=工人工匠资本家地主+贵族议会）
- [x] **阶级效果**：税收（人头/盐税按阶级负担系数，苛税打在下层、上层豁免；地税按地主持有）；奢侈品消费（阶级1-3必享/偶享，4级偶发，随规模与财富）；政治影响力（规模×权重 → 权势构成 UI）；幸福度（阶级基础值+税负+政策修正，奴隶恒低≤45）；动乱倾向（下层不满加权 → 稳定度漂移）
- [x] **阶级流动**（labor.ts 扩展）：识字率+财富驱动（佃农→自耕农→富农→地主；工匠→技术阶层→资本家→大贵族；工资低迷→下跌），月上限 1%，奴隶不流动，确定性无随机
- [x] **政策**：废农奴制（一次性：奴隶→佃农60%/自耕农40%，稳定度-15，废除农奴制效率惩罚×0.9→长期人口效率↑）；累进税（上层税负↑下层↓可开关）；普选（下层政治权重↑上层↓，稳定度混合影响）；写入状态与存档

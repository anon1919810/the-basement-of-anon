# 《卡尔特》(暂定名) · 架空世界大战略游戏

> 项目状态：**v0.6.0 已交付**（省份重构 + 循环地图 + 国界编辑器 + 视图切换 + 平滑缩放）
> 世界观来源：端明ちゃん 手稿 ｜ 地图来源：Azgaar 幻想地图生成器（世界名 Kalte / 卡尔特）

## 一句话
玩家扮演一个国家，在新历 1023 年、工业革命前夜（≈现实 1780 年）的架空世界「卡尔特」中，
治理经济、政治、文化、种族、宗教与国家机器的一切，在实时暂停的沙盘上与群雄争霸。

## 已实现（v0.6.0，见《执行清单-v0.6.md》）
- **v0.5 全部保留**：8 国全可玩 / 立体税制六税种连续滑块 / 产业链 13 建筑 / 7 级阶级 / 政策 /
  三级市场 17 商品 / 投资 / 时钟 / 存档（版本升 v7）/ 左侧治理面板（八分区 + Lucide 图标）/ 地形底图 / 经纬网格
- **省份重构（map.ts 聚类重写）**：大省拆分（>60 格按内部县 BFS 切分，目标 30-60 格）→
  小省并入（<10 格并入同属国最近邻）→ 海岛归并（相邻海岛间距 <35px 且同属国 → 多岛省）；
  结果 **55 省，规模 9-60 格**（盎格伦撒群岛 9 格为唯一边缘例外），确定性（同 seed 同结果）；
  **资源按新省份 id 重算**（data/resources_v2.json + 前端内嵌生成，复用 山地出矿/沿海渔盐/低地农业 规则，
  种子 1023）；8 国归属按新省份重派（v0.5 原则区域化：帝国北+西/洛林西岸/扎拉克中/伊尼亚斯东/
  诺曼尼亚南/奥兰治南沿海+海峡/盎格伦撒群岛+海峡/迷雾 x>=0.6W 不变）
- **循环地图（东西环绕）**：渲染左右各复制一份无缝拼接，平移跨过 0/W 边界连续；
  逻辑省距/海峡距/运费/县距全部环绕（dx = min(|x1-x2|, W-|x1-x2|)）；经纬网格/地形底图/迷雾环绕；
  hover/点击取最近副本
- **平滑缩放**：滚轮锚定光标 + 每帧插值缓动（rAF 合并重绘，0.4x~4x）；拖拽平移保留
- **国界编辑器（独立编辑模式）**：顶栏「编辑模式」开关（进入暂停时钟 + 提示防误触）；
  8 国 + 迷雾锁列表 → 点击省份改属 → 实时变色；迷雾省份不可点；
  **撤销/重做**（历史栈）、**清空到默认**、**保存**（localStorage `kalt-border-edits`，开局自动加载）、
  **导出 JSON**（`{provinceId: nationId}`，与 `PROVINCE_OWNER_OVERRIDES` 兼容，可下载文件）
- **视图切换**：地图右上角 政治/地形/人口/产值 四视图 + 图例 + hover 数值随视图切换
  （政治=国家色、地形=底图+细省界、人口=绿→红密度、产值=蓝→橙产出）
- **验证**：sim 断言 260 万全过——8 国各 10 年冒烟、洛林 50 年全断言（守恒/价格/阶级/确定性/存档往返）、
  新增 所有省规模 ∈ [8,90]、环绕距离正确（跨边界两点 < W/2）、编辑器导出/加载往返一致；
  `npm run build` 0 错误，oxlint 0 错误
- **8 国全可玩**：申斯戈维克帝国/洛林共和国/伊尼亚斯王国/奥兰治亲王国/北扎拉克选帝侯国/南扎拉克选帝侯国/盎格伦撒自由城邦/诺曼尼亚帝国；
  各国初始差异化（人口/识字率/政体/阶级分布/种族构成/资源禀赋/默认税率均按《世界观-卡尔特.md》）
- **立体税制**：六税种（土地/人头/消费/关税/特别 + 单一商品税），每税种连续滑块 0%-30%；
  阶级负担矩阵；产业链传导（煤炭税 → 铁锭 → 钢材 → 工具/武器/船坞全链传导）
- **人口系统修复**：初始人口按全图住房容量×0.75 水填法缩放（容量不足封顶）；
  月迁移软化（单省上限 容量×2%/月 + 推拉因子）
- **UI**：左侧治理面板（经济/市场/税收/阶级/人口/政策/投资/大事记 八分区，各配 Lucide 图标，可折叠）；
  右侧选中省份详情；TopBar 时钟速度/日期/国库/粮食/稳定度/人口/识字率/健康/国家切换/编辑模式开关
- **键盘快捷键**：空格=暂停/继续、1/2/3=速度、S=存档、N=新游戏（带确认）；
  编辑模式下 Ctrl+Z=撤销、Ctrl+Y=重做，其余快捷键禁用（防误触）

## 地图数据（已入库）
- `data/kalte_gridcells.json`：Azgaar GridCells 导出（9975 格，1920x1080，种子 720004209）
  - 字段：地形 t / 海拔 h(0-90) / 温度 temp(-31~19℃) / 降水 prec / 生物群系 b / 植被 f / 邻接 c / 多边形顶点 v
  - 世界样貌：两块大陆 + 群岛，陆地约 1/3，寒冷温带，绿植为主
- 说明：世界观手稿中的地理描述（盐海/萨迦河等）**作废**，以 Kalte 地图为准（用户已确认）

## 技术方向（草案）
- 前端：React + TS + Canvas（地图渲染），纯 TS 模拟引擎
- **实时暂停**（暂停/1x/2x/3x，dt 驱动）
- AI 事件生成：DeepSeek（复用覆巢之下模式，v0.3+，已让位人工事件）
- 后端：FastAPI + Supabase（云存档/排行榜，后期）
- 地图导入管线：Azgaar GridCells → 游戏地图（地形/海拔/温度/降水 → 省份与产出修正）

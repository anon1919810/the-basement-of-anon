# 《卡尔特》(暂定名) · 架空世界大战略游戏

> 项目状态：**v0.3.0 已交付**（产业链入游戏 + 阶级系统 + 政策）
> 世界观来源：端明ちゃん 手稿 ｜ 地图来源：Azgaar 幻想地图生成器（世界名 Kalte / 卡尔特）

## 一句话
玩家扮演一个国家，在新历 1023 年、工业革命前夜（≈现实 1780 年）的架空世界「卡尔特」中，
治理经济、政治、文化、种族、宗教与国家机器的一切，在实时暂停的沙盘上与群雄争霸。

## 已实现（v0.3.0，见《执行清单-v0.3.md》）
- **产业链入游戏**：商品表扩展为 17 种（资源→半成品→成品）；内嵌读取 `data/resources.json` 做省份资源修正（沃土=农业加成、矿藏省可建矿场、沿海=渔/盐、棉省=棉、寒带林=毛皮）；`investment.ts` 重构为 13 种建筑（农场/棉田/锯木/纺织/服装/煤矿/铁矿/炼铁/炼钢/工具/兵工厂/船坞/奢侈品工坊），输入→输出加工损耗、技能要求（无对应职业 POP → 产能打折）、省资源/基建/半成品解锁；下游建筑吃上游半成品（炼钢厂需铁锭 → 机械厂/兵工厂/船坞需钢材），建筑消耗输入从国家库存预扣并参与市场定价与进口补足
- **阶级系统**：7 级阶级（大贵族/资本家/技术阶层/市民工匠/自耕农工人/无业佃农/奴隶），POP = 阶级×职业×种族；各国初始分布按世界观（帝国农奴制多奴隶佃农、洛林市民工人无奴隶、伊尼亚斯工人工匠+贵族议会）；税收负担系数（苛税打在下层、上层豁免）、奢侈品仅上层、政治影响力权势构成、幸福度与动乱倾向、奴隶恒低幸福；阶级流动（识字率+财富驱动，确定性、有上限，奴隶不流动）
- **政策**：废农奴制（一次性：奴隶→佃农/自耕农，短期稳定度↓+长期人口效率↑）、累进税（上层↑下层↓可开关）、普选（下层政治权重↑稳定度混合影响），写入存档
- **UI**：NationPanel 新增「阶级」页（七级分布条形+权势构成+流动提示+政策区）；投资页扩展为建筑清单（解锁条件/输入输出/技能要求/运营状态）；市场价目 17 商品（宽表横向滚动）；地图 hover 显示省份资源；TopBar v0.3.0；存档版本升级 v4（旧档不兼容提示）
- **v0.2 保留**：三级市场（本地→区域→国家）、奢侈品、投资回报、行政区三级制、地图美化、事件系统移除（人工事件休眠）
- **验证**：50 年无头沙盒 5,058,050 项断言全过（守恒含建筑/阶级恒正/价格 clamp/确定性/存档往返/帝国废奴冒烟），`npm run build` 0 错误，oxlint 0 错误

## 地图数据（已入库）
- `data/kalte_gridcells.json`：Azgaar GridCells 导出（9975 格，1920x1080，种子 720004209）
  - 字段：地形 t / 海拔 h(0-90) / 温度 temp(-31~19℃) / 降水 prec / 生物群系 b / 植被 f / 邻接 c / 多边形顶点 v
  - 世界样貌：两块大陆 + 群岛，陆地约 1/3，寒冷温带，绿植为主
- 说明：世界观手稿中的地理描述（盐海/萨迦河等）**作废**，以 Kalte 地图为准（用户已确认）

## 技术方向（草案）
- 前端：React + TS + Canvas（地图渲染），纯 TS 模拟引擎
- **实时暂停**（暂停/1x/2x/3x，dt 驱动）
- AI 事件生成：DeepSeek（复用覆巢之下模式，v0.3+，已让位人工事件）
- 后端：FastAPI + Supabase（云存档/排行榜，后期）
- 地图导入管线：Azgaar GridCells → 游戏地图（地形/海拔/温度/降水 → 省份与产出修正）

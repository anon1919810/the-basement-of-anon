# 《卡尔特》(暂定名) · 架空世界大战略游戏

> 项目状态：**v0.4.0 已交付**（8 国全可玩 + 立体税制）
> 世界观来源：端明ちゃん 手稿 ｜ 地图来源：Azgaar 幻想地图生成器（世界名 Kalte / 卡尔特）

## 一句话
玩家扮演一个国家，在新历 1023 年、工业革命前夜（≈现实 1780 年）的架空世界「卡尔特」中，
治理经济、政治、文化、种族、宗教与国家机器的一切，在实时暂停的沙盘上与群雄争霸。

## 已实现（v0.4.0，见《执行清单-v0.4.md》）
- **8 国全可玩**：申斯戈维克帝国/洛林共和国/伊尼亚斯王国/奥兰治亲王国/北扎拉克选帝侯国/南扎拉克选帝侯国/盎格伦撒自由城邦/诺曼尼亚帝国；
  地图左+中央+群岛省份重分给 8 势力（撤并北境诸部/灰漠/南岭/盐海城邦/凯森/海峡等填充势力），右侧迷雾新大陆不动；
  各国初始差异化（人口/识字率/政体/阶级分布/种族构成/资源禀赋/默认税率均按《世界观-卡尔特.md》）；
  TopBar 下拉 + 新游戏弹窗 8 国全开放；切国即载入该国初始状态（废农奴制在存在奴隶的国默认可用）
- **立体税制**：六税种（土地/人头/消费/关税/特别 + 单一商品税），每税种**连续滑块 0%-30%**；
  **阶级负担矩阵**（土地→持地者、人头→自由民奴隶免、消费→消费者、关税→商人资本家、特别→按贸易运输量）；
  **单一商品税全部 17 商品可选**（可多选叠加）：买方有效价 = 市价×(1+税率)，收入 = 税率×成交量进国库；
  **盐回归普通商品**（取消盐税专档，走供需定价，可被选作商品税对象）；
  **产业链传导**：输入品征税 → 下游按税后价计成本 → 成品价随成本上升（煤炭税→铁锭→钢材→工具/武器/船坞全链传导，进市场定价）
- **v0.3 保留**：产业链 13 建筑、7 级阶级、政策（废农奴制/累进税/普选）、三级市场 17 商品、投资、时钟、存档
- **UI**：NationPanel 新增「税收」页（五税种滑块 + 商品税滑块列表可筛选 + 各税种实收 + 阶级负担明细 + 传导提示）；
  市场价目显示 市价→有效价；存档升级 v5（旧档 v4/v3 提示不兼容）
- **验证**：8 国各 10 年冒烟（随机税制策略）不崩/无 NaN/守恒；洛林 50 年全断言（守恒含六税种账本一致/价格恒正 clamp/阶级恒正/确定性同种子/存档往返）；
  商品税传导实证（单元级 + 集成级：煤炭税 15% → 煤有效价 +15%、炼铁厂输入成本↑、钢材/工具价随成本上升、商品税收入>0）；
  `npm run build` 0 错误，oxlint 0 错误

## 地图数据（已入库）
- `data/kalte_gridcells.json`：Azgaar GridCells 导出（9975 格，1920x1080，种子 720004209）
  - 字段：地形 t / 海拔 h(0-90) / 温度 temp(-31~19℃) / 降水 prec / 生物群系 b / 植被 f / 邻接 c / 多边形顶点 v
  - 世界样貌：两块大陆 + 群岛，陆地约 1/3，寒冷温带，绿植为主
- 说明：世界观手稿中的地理描述（盐海/萨迦河等）**作废**，以 Kalte 地图为准（用户已确认）

## 技术方向（草案）
- 前端：React + TS + Canvas（地图渲染），纯 TS 模拟引擎
- **实时暂停**（暂停/1x/2x/3x，dt 驱动）
- AI 事件生成：DeepSeek（复用覆巢之下模式，v0.3+，已让位人工事件）
- 后端：FastAPI + Supabase（云存档/排行榜，后期）
- 地图导入管线：Azgaar GridCells → 游戏地图（地形/海拔/温度/降水 → 省份与产出修正）

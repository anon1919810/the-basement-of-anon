# 《卡尔特》(暂定名) · 架空世界大战略游戏

> 项目状态：**v0.1.0 已交付**（行政区三级制 + 地图美化 + 经济全循环）
> 世界观来源：端明ちゃん 手稿 ｜ 地图来源：Azgaar 幻想地图生成器（世界名 Kalte / 卡尔特）

## 一句话
玩家扮演一个国家，在新历 1023 年、工业革命前夜（≈现实 1780 年）的架空世界「卡尔特」中，
治理经济、政治、文化、种族、宗教与国家机器的一切，在实时暂停的沙盘上与群雄争霸。

## 已实现（v0.1.0，见《执行清单-v0.1.md》）
- **行政区三级制**：cell → 县（确定性区域生长，5-15 格）→ 省（20-80 格，山脉/气候为界）→ 3 国辖区 + 迷雾新大陆
- **地图美化**：海洋水深渐变、地形×气候着色、国界柔化多层、海岸提亮、县/省/国界三级、hover 摘要
- **经济全循环**：聚合 POP（职业×种族）、需求四件套→幸福度→效率、劳动力市场（工资/识字率梯子/转职）、人口增长+住房上限、国家市场供需定价+简化国际贸易、物流运费+基建、四税种财政+支出、价格信号
- **事件**：12 条 v0.0.0 + 3 条 v0.1（粮价暴涨/工业繁荣/国库破产）
- **验证**：50 年无头沙盒 550,367 项断言全过（守恒/确定性/崩溃保护），`npm run build` 0 错误

## 地图数据（已入库）
- `data/kalte_gridcells.json`：Azgaar GridCells 导出（9975 格，1920x1080，种子 720004209）
  - 字段：地形 t / 海拔 h(0-90) / 温度 temp(-31~19℃) / 降水 prec / 生物群系 b / 植被 f / 邻接 c / 多边形顶点 v
  - 世界样貌：两块大陆 + 群岛，陆地约 1/3，寒冷温带，绿植为主
- 说明：世界观手稿中的地理描述（盐海/萨迦河等）**作废**，以 Kalte 地图为准（用户已确认）

## 工具
- `tools/probe_azgaar.py`：探查 GridCells 数据结构
- `tools/render_kalte.py`：把 GridCells 渲染成 PNG 预览（验证数据可用）

## 技术方向（草案）
- 前端：React + TS + Canvas（地图渲染），纯 TS 模拟引擎
- **实时暂停**（暂停/1x/2x/3x，dt 驱动）
- AI 事件生成：DeepSeek（复用覆巢之下模式，v0.2+）
- 后端：FastAPI + Supabase（云存档/排行榜，后期）
- 地图导入管线：Azgaar GridCells → 游戏地图（地形/海拔/温度/降水 → 省份与产出修正）

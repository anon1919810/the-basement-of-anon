# 《卡尔特》(暂定名) · 架空世界大战略游戏

> 项目状态：**v0.2.0 已交付**（三级市场 + 奢侈品 + 投资回报 + 事件系统移除）
> 世界观来源：端明ちゃん 手稿 ｜ 地图来源：Azgaar 幻想地图生成器（世界名 Kalte / 卡尔特）

## 一句话
玩家扮演一个国家，在新历 1023 年、工业革命前夜（≈现实 1780 年）的架空世界「卡尔特」中，
治理经济、政治、文化、种族、宗教与国家机器的一切，在实时暂停的沙盘上与群雄争霸。

## 已实现（v0.2.0，见《执行清单-v0.2.md》）
- **事件系统移除**：自动事件生成/模板池/弹窗全部移除；`manualEvents.ts` 人工事件预留（空列表 + 填写格式注释，state 休眠检查点）；事件日志改为「大事记」（破产/工厂落成等被动记录）
- **三级市场（本地→区域→国家）**：县内自产自销无运费；省内县间贸易（距离×地形运费）；省间调运（跨省运费更高）；盈余向上流动、缺口向下补足；价格信号跨层传导（国家→区域→本地，权重 15%/20%）；守恒逐月断言
- **奢侈品**：工匠/工程师附加产出（× 省奢侈品潜力）；高收入 POP 消费（国民财富↑ → 需求↑）；独立供需定价（clamp 0.4~2.5），纳入三级市场与国际贸易
- **投资回报**：精英/富裕 POP 按月分得全国资本回报池（贸易顺差 + 工业利润，按财富占比）；玩家投资面板（纺织厂/冶铁厂/船坞，按省份选址、受资源/基建解锁），建造成本+工期 → 月度回报（市价 × 产能 − 运营成本，市价低迷亏损），取消退款按完成度
- **行政区三级制 / 地图美化 / 经济全循环**（v0.1 保留）：cell→县→省→3 国辖区 + 迷雾新大陆；海洋渐变/柔化国界/hover 摘要；聚合 POP、需求四件套、劳动力市场、物流运费、四税种财政
- **验证**：50 年无头沙盒 1,006,243 项断言全过（守恒/确定性/崩溃保护/投资账目），`npm run build` 0 错误，oxlint 0 错误

## 地图数据（已入库）
- `data/kalte_gridcells.json`：Azgaar GridCells 导出（9975 格，1920x1080，种子 720004209）
  - 字段：地形 t / 海拔 h(0-90) / 温度 temp(-31~19℃) / 降水 prec / 生物群系 b / 植被 f / 邻接 c / 多边形顶点 v
  - 世界样貌：两块大陆 + 群岛，陆地约 1/3，寒冷温带，绿植为主
- 说明：世界观手稿中的地理描述（盐海/萨迦河等）**作废**，以 Kalte 地图为准（用户已确认）

## 技术方向（草案）
- 前端：React + TS + Canvas（地图渲染），纯 TS 模拟引擎
- **实时暂停**（暂停/1x/2x/3x，dt 驱动）
- AI 事件生成：DeepSeek（复用覆巢之下模式，v0.3+，已让位人工事件）
- 后端：FastAPI + Supabase（云存档/排行榜，后期）
- 地图导入管线：Azgaar GridCells → 游戏地图（地形/海拔/温度/降水 → 省份与产出修正）

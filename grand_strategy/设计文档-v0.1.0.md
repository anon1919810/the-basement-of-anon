# 《卡尔特》设计文档 v0.1.0

> 架空世界大战略 · 实时暂停 · 工业革命前夜 · 世界观见《世界观-卡尔特.md》
> 技术：React + TS + Canvas + ECharts；纯 TS 模拟引擎；DeepSeek 事件生成；FastAPI+Supabase（后期云存档/排行）

---

## 1. 一句话

玩家扮演卡尔特世界中的一个国家，在**实时暂停**的沙盘上治理经济、政治、文化、种族、宗教与国家机器，在 1780 年代水平的生产力下，或复兴故国，或开辟新世。

## 2. 核心循环（实时）

```
时钟流动（暂停/1x/2x/3x）
  └─ 每"日"结算：人口/经济/文化/宗教状态 → 生成事件流 → AI 对手行动
玩家随时可：下政令（政策/预算/外交/战争/基建）→ 事件抉择 → 观察反馈
时间单位：1 年 = 12 个月，月内按日 tick；一局典型 50-100 年
```

## 3. 六系统详设

### 3.1 经济系统
- **核心资源**：粮食（人口上限/满意度）、货币（财政）、工业产出（军工/基建）、贸易额（商路/关税）
- **财政**：税收（人头/土地/关税/盐税）← 税率政策；支出（行政/军事/基建/王室）
- **贸易**：商路 = 地理拓扑（海路借洋流/季风，陆路借河谷/隘口）；关税影响收入与商路繁荣
- **农业**：受气候（季风年景）、地形（平原/山地）、农奴制/自由农政策影响
- **工业萌芽**：煤铁资源 → 工厂产能（1780 水平：纺织/钢铁/造船）
- 地图交互：省份产出 = 地形×气候×资源×政策

### 3.2 政治系统
- **合法性/稳定度**：合法性（继承/宪政/选举）× 稳定度（民生/战乱/宗教冲突）
- **派系**：贵族/官僚/军队/商人/教士/平民——各自支持度与诉求
- **政体**：君主专制 / 君主立宪 / 共和 / 商人共和 / 选帝侯制（按国家设定，事件可推动政体变迁）
- **政策卡**：每段时期可选 1-2 项改革（废农奴制、建立官僚制、宗教宽容、普选…），有代价与长期收益

### 3.3 文化系统
- **文化圈**：乌萨斯文化圈/菲林-黎博利圈/阿戈尔海洋圈/扎拉克圈/诺曼圈——同化/融合/对立
- **识字率**：影响科技研究、征兵质量、改革支持度（各国初始识字率取自世界观）
- **学术与思潮**：启蒙/共和/民族主义/宗教复兴——思潮随时间与事件传播（洛林是思想中心）
- 文化产出：宫廷文化、艺术声望（软实力，影响外交与合法性）

### 3.4 种族系统
- 人口按**种族分层**（八族各有占比、分布省份、职业倾向）
- **政策光谱**：宽容（平等/融合/通婚）↔ 压迫（歧视/强制同化/驱逐）
- 机制：压迫 → 短期资源榨取 ↑、但叛乱/分裂风险 ↑；宽容 → 长期人口效率 ↑、但主体民族不满
- 事件：种族起义、移民潮、精英外流（萨卡兹问题、乌萨斯农奴问题）

### 3.5 宗教系统
- 卡尔特多神信仰 + 地区教派（可按国家设定深化）
- **国教/信仰自由** 政策：教士派系支持 vs 宗教少数满意度
- 宗教冲突：与种族/政治交叉（"异教起义"、"圣战"、宗教改革运动）
- 事件：教廷/大祭司干预、宗教战争、世俗化运动（启蒙思潮压制宗教势力）

### 3.6 治理系统
- **腐败**：官僚体系腐败度（高税+低薪 → 腐败↑）；反腐政策（成本高，长期收益）
- **官僚效率**：识字率×制度（废除恩赐制、建立考功制）
- **基建**：道路/港口/堡垒（地图上的工程，连接省份）
- **军队**：常备军/征召兵；军费与将领（军事改革）
- **外交**：关系、同盟、边境争端、干涉他国（伊尼亚斯干涉奥兰治等既定剧情）

## 4. 实时暂停引擎
- 游戏时钟：dt 驱动（1 tick = 1 游戏日），`pause / speed 1x/2x/3x`
- **确定性**：同种子同输入 → 同结果（便于测试与回放）
- 事件队列：每日生成候选事件（宏观/国家/省份/人物），玩家暂停时从容决策
- 存档：自动 + 手动（localStorage，云端后期）

## 5. 地图与省份（Azgaar 导入管线）
- `data/kalte_gridcells.json` → 导入器解析：地形 t/海拔 h/温度/降水/生物群系/邻接/多边形
- **省份** = 相邻陆地单元聚簇（大小适中，便于管理）；海洋单元构成海域/航线拓扑
- 省份属性：气候区（由温度/降水推导）→ 农业修正；地形 → 行军/筑城/矿藏；河流 → 贸易/灌溉
- 渲染：Canvas 绘制多边形省份（海岸/等高线/气候着色），ECharts 叠经济图表
- 国家 = 省份集合（初始按世界观 8 国划分，端明ちゃん可在 Azgaar 或游戏内调整国界）

## 6. AI 事件生成（DeepSeek）
- 复用覆巢之下模式：后端 `POST /api/events`，输入 {国家/时代/宗教/种族/近期事件} → 生成 1-3 条符合世界观的事件（标题/正文/选项/影响）
- 失败兜底：内置事件模板池（起义/丰收/瘟疫/外交照会…），保证离线可玩

## 7. UI / 技术栈
- 顶栏：时钟（暂停/速度）、年份、国库/粮食/稳定度、调参
- 主区：Canvas 地图（点击省份 → 详情侧栏）
- 侧栏：国家面板（六系统标签页）、政策、外交、军力
- 事件弹窗（实时暂停时弹出，可"稍后处理"）
- 字体/风格延续撷菁轩的极简风（白底/细线/绿强调），地图用 Canvas

## 8. v0.0.0 范围（首个可玩原型）
1. 地图导入 + Canvas 渲染（省份/气候/地形着色，点击选中）
2. 时钟引擎（暂停/1x/2x）+ 1 年 12 月推进
3. 经济最小循环：税收 → 国库 → 支出（军/行政/基建）→ 粮食 → 人口
4. 一个可玩国家（默认洛林共和国，或可选 2-3 国）+ 基础省份产出
5. 事件系统（模板 + AI 可选接入）
6. 存档（localStorage）
- 不含（后续）：战争/外交全系统、文化/种族/宗教深度、多国 AI 完整行为

## 9. 数值初稿（起点，实测定调）
| 参数 | 默认 |
|---|---|
| 初始资金（国库） | 按国家规模（帝国 5000/小国 800 单位） |
| 税率档位 | 轻/中/重/苛（影响收入与稳定度） |
| 粮食 | 人口/季（农产值 × 地形修正 × 政策） |
| 省份产出 | 地形×气候×资源×识字率系数 |
| 事件频率 | 每 1-3 月 1 条（宏观+国家） |
| 识字率增长 | 基础教育年 +0.3~0.8%（按国家） |
| 同化速度 | 宽容政策 + 基础速率 |

## 10. 测试点（无头模拟）
- 导入器：省份聚簇数、海陆一致、地形属性正确
- 时钟：暂停/变速下状态推进正确（dt 无漂移）
- 经济：税收-支出-国库守恒；粮荒 → 稳定度下降 → 起义事件
- 确定性：同种子两次运行结果一致
- 30 年沙盒：国库非负崩溃保护、事件可处理、存档读写
